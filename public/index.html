Configuration requise

Class Connect a besoin d'un projet Firebase (gratuit) pour fonctionner.

  1. Crée un projet sur console.firebase.google.com.
  2. Active Authentication → E-mail/Mot de passe et crée une base Firestore.
  3. Colle les règles de firestore.rules dans l'onglet Règles de Firestore.
  4. Copie la configuration Web de ton projet dans public/js/config.js.
